도메인용도도구 (쉼표구분)우선순위추출 지침

같은 이름으로 저장하면 수정(upsert). 용도를 등록 때 선택합니다 — 문서 전용은 대화 분류·폴백에 끼지 않고 소스에 지정해 문서 구조화에만, 대화 전용은 세션 분류에만, 대화+문서는 양쪽에 쓰입니다. 대화 용도 도메인 중 어떤 도구와도 매칭 안 되는 세션은 그중 최하순위 도메인으로 분류됩니다. 변경은 다음 파이프라인 실행(야간)부터 신규분에 반영 — 소급 재분류 없음. 삭제는 의도적으로 UI에 없습니다.

구조화 원천 테이블 접점 2 — 저쪽 테이블은 읽기 전용, 등록은 사람 전용

소스테이블id시간 역할 매핑유형그래프 도메인사용
역할 매핑 — 본문(body) 또는 지문(question)+답(answer) 중 최소 하나: ② 적재 원천 테이블 → 검색 코퍼스 (corpus_docs·청크) 즉시 예약: 야간 03:10 증분 자동 ⑤ 구조화 검색 코퍼스 → 지식그래프 · 그래프 도메인 지정 소스만 즉시 예약

즉시 = 누르면 지금 실행 · 예약 = 지금은 표시만, 야간 배치가 처리 (또는 [지금 구조화]로 당겨 실행).
같은 소스 이름으로 저장하면 수정(upsert) — 수정·재적재·드라이런·초기화는 1개만 체크, 적재·구조화·삭제는 여러 개 체크해 일괄 실행. 그래프 도메인 미지정 = 검색 전용(구조화 안 함, 아래 처리 현황에 안 뜸). 원천 테이블에는 절대 쓰지 않습니다(SELECT만) — 끄려면 '사용' 해제.

야간 배치 1회에 판정할 문서 수 (기본 200 — 즉시 버튼은 무시하고 끝까지) LLM 판정을 동시에 보낼 개수 (기본 16 — 서빙 GPU 여유에 맞춰, 클수록 빠름) 판정 프롬프트에 넣는 본문 최대 글자 수 (기본 3000, 0=문서 전체 — 길수록 정확하나 느리고 토큰↑) 0=문서 1건씩 / N=입력 N토큰 예산까지 여러 문서를 요청 1건으로 묶어 판정 (속도↑, 묶음당 최대 8건, 누락분 단건 폴백) 구조화 판정 전용 모델 (빈값=채팅 기본 — 작은 모델로 충분하면 비용 절감, 같은 채팅 호스트에서 서빙돼야 함) 시맨틱 검색용 조각 크기 (기본 1,200 — 본문이 길면 여러 청크로 분할, 재청킹·재임베딩은 야간 배치가 갱신분만) 인접 청크 겹침 (기본 150 — 경계에 걸린 문장 보존용) 추론 모델의 생각(thinking) 출력을 끄고 판정 (기본 켜짐 — 실측 7~8배 빠르고 판정 품질 동일)
