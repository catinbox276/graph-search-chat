# 피드백 처리 — 이전 ↔ 현재 챗봇 비교 피드백 대응

> 주신 **피드백(신규 문제점·좋은 점·의문사항·개선 방안 9가지)** 을 항목별로 어떻게 처리했는지 정리한 문서입니다. (피드백과 무관하게 새로 추가한 기능은 → `2-추가-기능.md`)
>
> 누구나 이해할 수 있게 쉽게 썼습니다.

---

## 한눈에 보기 — 개선 방안 9가지 처리 현황

| # | 피드백(개선 방안) | 처리 방법 | 상태 |
|---|---|---|---|
| 1 | 언어 필터링 | 질문이 영어·혼용이든 **답변은 항상 한국어로만** 하도록 지침 강화(고유명사·코드는 원문 유지) | ✅ 완료 |
| 2 | 마크다운 `**` 파싱 실패 | `**중요:**내용` 처럼 별표 뒤 공백 없이 한글이 붙어도 굵게 되도록 **한글 친화 확장** 적용 | ✅ 완료 |
| 3 | 지원 불가 영역에 되묻기 | 지원 밖이면 **되묻지 말고 즉시 "지원하지 않습니다"** 라고 명시 (거절이 되묻기보다 우선) | ✅ 완료 |
| 4 | 답변 불가 시 공백 응답 | **빈 응답 금지.** "답변할 수 없습니다" + 사유(근거 없음/데이터 없음/지원 밖) + 다음 행동 안내 | ✅ 완료 |
| 5 | 문법 오류 정정 프로세스 | 검색 **전에** 명백한 오타·문법을 **1회 교정**해 처리 (예: "게좌"→"계좌") | ✅ 완료 |
| 6 | 되묻기 전용 프로세스 | 막연한 질문은 **되묻기 전용 흐름**으로 분기 + 화면에 "💬 되묻기" 카드로 구분 표시 | ✅ 완료(보수적) |
| 7 | 행동 지침 설명 시 1회 확인 | 위험한 조작 안내 전 확인 단계 — **현재 보류** (아래 설명) | ⏸ 보류 |
| 8 | 증적 없음 → 2단계 분리 | ①"근거를 못 찾았습니다" 먼저 명시 → ②그 다음에만 유사 자료 제안 | ✅ 완료 |
| 9 | gpms 질문 실패 원인 분석 | **제외** (진행 중 "gpms는 무시" 지시 주심) | ⏸ 제외 |

> **7번(행동 지침 1회 확인)** 은 원래 "위험한 실행 전 사람이 승인"하는 안전장치인데, 현재 도우미의 도구가 전부 **읽기 전용**(검색·문서 읽기)이라 막을 위험한 실행 자체가 없습니다. 그래서 지금은 보류하고, 나중에 쓰기 기능이 생기면 승인 단계를 붙이는 게 맞습니다.

## 신규 문제점 — 어떻게 고쳤나

**① 언어 필터링 미작동** → 답을 **항상 한국어로만** 하도록 지침을 강화했어요. 질문이 영어여도 한국어로 답합니다. (고유명사·코드·표 안 값은 원문 유지)

**② 마크다운 `**` 처리 불가** → 별표 뒤에 공백 없이 한글이 붙는 흔한 형태(`**항목:**설명`)가 굵게 안 되던 문제를, 한글에 맞춘 확장을 적용해 고쳤습니다. 실제 화면에서 `**중요:**내용` → **중요:** 처럼 굵게 나오는 것을 확인했어요.

**③ 문법 오류 처리 프로세스** → 질문에 오타가 있으면 **한 번 고쳐서** 검색합니다. 뜻은 절대 바꾸지 않고 표기만 정정.

**④ 지원 불가 영역에 되묻기** → 못 하는 분야는 **빙빙 돌리지 않고** 바로 "죄송하지만 그 주제는 지원하지 않습니다"라고 명시하고 가능한 주제를 안내합니다.

**비유:** 도서관 사서가 "그 책은 저희 도서관에 없습니다"라고 분명히 말해 주는 것과 같아요.

## 좋은 점 — 유지/개선

| 좋은 점 | 처리 |
|---|---|
| 1. 증적(근거) 남기는 처리 우수 | 그대로 유지 (변경 없음) |
| 2. 증적 없으면 "없다" 명시 | **2단계로 분리** — ①없음 명시 → ②유사 자료 제안 (개선안 8과 동일) |
| 3. 행동 순서 설명 | 위험 안내엔 1회 확인 필요 → 신중히 설계(개선안 7, 현재 보류) |
| 4. 사용자 질문 포함 예시 제공 | 그대로 유지 (변경 없음) |
| 5. 고유명사 강제 변환 안 함 | 그대로 유지 (변경 없음) |

## 의문사항 — 확인 결과

- **되묻기 프로세스 미정의** → 이제 **전용 흐름**을 만들었습니다(개선안 6). 막연한 질문은 되묻기로 분기하고 화면에 구분 표시.
- **답변 불가 질문의 공백** → **빈 응답 금지**로 처리(개선안 4). "답변할 수 없습니다" + 사유를 반드시 표기.
- **gpms 실패 원인** → 확인해 보니 코드·문서 어디에도 gpms 흔적이 없어 **적재되지 않은 외부 시스템**으로 추정됩니다. 진행 중 "gpms는 무시" 지시를 주셔서 **분석은 제외**했습니다. (원인 분석이 필요하면 실패한 세션 정보만 주시면 로그에서 추적 가능)
